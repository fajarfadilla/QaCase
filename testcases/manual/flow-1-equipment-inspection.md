# Flow 1 - Equipment Inspection (Manual)

## Assumptions

The case leaves these behaviours unspecified. The test cases below are written against these assumptions.
| ID | Ambiguity | Assumption | Affects | Question for PO |
|----|-----------|------------|---------|-----------------|
| AS-08 | Uniqueness of Form Code is not stated | Form Code is unique within a Tenant; the same code can exist in another Tenant | EI-M-004 | Is Form Code unique per Tenant or globally? Can it be changed after Inspection Submissions exist? |
| AS-09 | Radio allows "up to four options" but no minimum | A Radio Field needs 2 to 4 options | EI-M-003 | What is the minimum number of options for a Radio Field? |
| AS-10 | Field configuration (label, options, mandatory) is not described | Every Field needs a label; a Select needs at least 1 option; each Field can be set Mandatory or Optional, and WeMine enforces it | EI-M-009 | Which Field properties can be configured? Can Fields be marked mandatory? |
| AS-11 | Who can use the Form Builder is not stated | Only Tenant admins can open the Form Builder | EI-A-006 | Which roles can create and edit Forms? |
| AS-12 | Behaviour after a Form is edited is not described | Changes reach WeMine on the next Master Data refresh; existing Inspection Submissions keep the Fields and values they were submitted with | EI-M-005 | Are Forms versioned? What happens to Inspection Submissions made with an older version? |
| AS-13 | The "Form Code" field on WeMine is not described | Form Code is a Select listing the Tenant's Forms from Master Data | EI-M-007 | Is Form Code picked from a list, typed, or scanned (e.g. QR on the equipment)? |
| AS-14 | "List of previous submissions" doesn't say whose, in what order, or whether they can be changed | The list shows the signed-in Employee's own Inspection Submissions, newest first, and they are read-only after submission | EI-M-006 | Whose submissions are listed? Can a submission be edited or deleted? |
| AS-15 | Offline submission is implied by the offline goal but not described for this flow | An Inspection Submission made offline is saved as pending and synced automatically once online, without duplicates | EI-M-010 | How is a pending submission handled if its Form changed before it synced? |

| ID | Title | Priority | Test Type | Preconditions | Steps | Expected Result |
|----|-------|----------|-----------|---------------|-------|-----------------|
