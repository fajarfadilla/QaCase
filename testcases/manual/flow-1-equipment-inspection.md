# Flow 1 - Equipment Inspection (Manual)

## Assumptions

The case leaves these behaviours unspecified. The test cases below are written against these assumptions.
| ID | Ambiguity | Assumption | Affects | Question for PO |
|----|-----------|------------|---------|-----------------|
| AS-10 | Only a maximum of 50 Fields is given | A Form needs at least 1 Field to be saved | EI-M-004 | Can a Form with zero Fields be saved? |
| AS-11 | Uniqueness of Form Code is not stated | Form Code is unique within a Tenant; the same code can exist in another Tenant | EI-M-007 | Is Form Code unique per Tenant or globally? Can it be changed after Inspection Submissions exist? |
| AS-12 | Radio allows "up to four options" but no minimum | A Radio Field needs 2 to 4 options | EI-M-005, EI-M-006 | What is the minimum number of options for a Radio Field? |
| AS-13 | Field configuration (label, options, mandatory) is not described | Every Field needs a label; a Select needs at least 1 option; each Field can be set Mandatory or Optional, and WeMine enforces it | EI-M-008, EI-M-015 | Which Field properties can be configured? Can Fields be marked mandatory? |
| AS-14 | Who can use the Form Builder is not stated | Only Tenant admins can open the Form Builder | EI-M-011 | Which roles can create and edit Forms? |
| AS-15 | Behaviour after a Form is edited is not described | Changes reach WeMine on the next Master Data refresh; existing Inspection Submissions keep the Fields and values they were submitted with | EI-M-009, EI-M-022 | Are Forms versioned? What happens to Inspection Submissions made with an older version? |
| AS-16 | The "Form Code" field on WeMine is not described | Form Code is a Select listing the Tenant's Forms from Master Data | EI-M-013, EI-M-023 | Is Form Code picked from a list, typed, or scanned (e.g. QR on the equipment)? |
| AS-17 | "List of previous submissions" doesn't say whose, in what order, or whether they can be changed | The list shows the signed-in Employee's own Inspection Submissions, newest first, and they are read-only after submission | EI-M-012, EI-M-024 | Whose submissions are listed? Can a submission be edited or deleted? |
| AS-18 | Changing Form Code after filling Fields is not described | WeMine asks for confirmation, then clears the entered values and loads the new Form's Fields | EI-M-016 | Should entered values be kept, discarded, or should Form Code be locked once filling starts? |
| AS-19 | Offline submission is implied by the offline goal but not described for this flow | An Inspection Submission made offline is saved as pending and synced automatically once online, without duplicates | EI-M-017, EI-M-022 | How is a pending submission handled if its Form changed before it synced? |
| AS-20 | No input limits are given for Text, Image Picker or Date Picker Fields | Text accepts up to 500 characters; Image Picker accepts camera and gallery and handles large photos; Date Picker allows any date | EI-M-019, EI-M-020, EI-M-021 | What are the limits per Field type (text length, image count and size, date range)? |
