# Flow 0 - Sign In (Manual)

## Assumptions

The case leaves these behaviours unspecified. The test cases below are written against these assumptions;
| ID | Ambiguity | Assumption | Affects | Question for PO |
|----|-----------|------------|---------|-----------------|
| AS-01 | Step 3 says the backend "will lookup their tenant informations" but not what happens when the username is not found | An unknown username shows an error and the Microsoft login screen is not opened | SI-M-003 | What should the user see for a username that doesn't belong to any Tenant? |
| AS-02 | Username format and matching rules are not defined | Username is case-insensitive and leading/trailing spaces are trimmed | SI-M-004 | Is the username case-sensitive? Is it an email or a free-form ID? |
| AS-03 | Nothing links the username typed in step 1 to the Microsoft account used in step 4 | Signing in to Microsoft as a different account than the username entered is rejected | SI-M-007 | Must the Microsoft account match the username entered? What happens if it doesn't? |
| AS-04 | Step 7 doesn't say what happens if a Master Data request fails or the connection drops | A partial download is never marked complete; Retry resumes or restarts it without creating duplicates | SI-M-008, SI-M-009 | Should a failed download resume from the failed item or restart from scratch? |
| AS-05 | Step 8 says "restart after updating their master data for the first time" | The restart prompt appears only after the first successful download on a device, not on later sign-ins or refreshes | SI-M-010 | Is "first time" per device, per Employee, or per Master Data version? |
| AS-06 | Step 8 refers to "app" without saying whether WeMineOffice also prompts for a restart | WeMine shows the restart prompt; WeMineOffice may reload instead, so the test accepts either | SI-M-002 | Does WeMineOffice show a restart prompt, reload automatically, or neither? |
| AS-07 | The apps "can be operated fully" offline, but sign-in needs the backend and Microsoft | A fresh sign-in needs a connection; an existing session opens and works offline from cached Master Data | SI-M-011, SI-M-012 | Is a first-time sign-in expected to work offline in any way? How long does an offline session stay valid? |
| AS-08 | Account revocation is not mentioned | Disabling an Employee's Microsoft account blocks new sign-ins and invalidates existing sessions on the next online check | SI-M-013 | How often does the app revalidate a session, and what happens to unsynced data when it is revoked? |
